# Прогнозирование цен подержанных автомобилей

Курсовая работа по дисциплине «Основы искусственных нейронных сетей». Цель — оценить цену автомобиля по его характеристикам на данных соревнования [Regression of Used Car Prices](https://www.kaggle.com/competitions/playground-series-s4e9/overview). Метрика соревнования — RMSE.

## Проверка входных данных

Проект использует Python 3.11 или новее. В окружении, где pandas ещё не установлен, установите зависимости:

```bash
python -m pip install -r requirements.txt
```

В ноутбуке Kaggle подключите соревнование как источник данных. Из каталога с файлами проекта запустите:

```bash
python main.py
```

Если CSV лежат в другом каталоге, укажите его явно:

```bash
python main.py --data-dir /путь/к/данным
```

Скрипт читает `train.csv`, `test.csv` и `sample_submission.csv`, сверяет признаки, цены и идентификаторы, затем выводит сводку в JSON. Идентификатор и имя целевого столбца заданы в `config.toml`.

## Валидация и базовые модели

Команда `python main.py --stage baselines` формирует пять фолдов и сравнивает модели по RMSE в исходных единицах цены. Перед разбиением строки сортируются по `id`. Для стратификации цена разбивается по квантилям на десять групп, затем применяется StratifiedKFold с перемешиванием и seed 42. Параметры заданы в `config.toml`.

Каждая строка получила один прогноз от модели, обученной на остальных четырёх фолдах. Общая медиана дала RMSE 79 892,84. Медиана по паре «марка и модель» с подстановкой общей медианы для неизвестных пар дала 75 582,53. Линейная регрессия по году выпуска и пробегу дала 75 463,81. Итоговый RMSE рассчитан по всем 188 533 проверочным прогнозам каждой модели.

Команда сохраняет соответствие `id → fold` в `results/validation/folds.csv`. Его также можно скачать из результатов прогона Kaggle. SHA-256 файла — `0f091d0d267a4b69df7dff61995166f560e83b373ed78b3bb220f897b09c723e`.

[Итоговые метрики](results/validation/baselines.csv) · [RMSE по фолдам](results/validation/rmse_by_fold.csv) · [Прогон на Kaggle](https://www.kaggle.com/code/naum0v7/used-car-prices-baselines)

## Предобработка и классические регрессоры

Команда `python main.py --stage classical` читает назначения фолдов из `results/validation/folds.csv`. Путь к скачанному файлу можно передать через `--folds-file`. Заполнение пропусков, кодирование, масштабирование и обучение моделей выполняются внутри каждого обучающего фолда. Общее RMSE считается по всем проверочным строкам.

[Сравнение моделей и предобработки](results/classical/README.md) · [Прогон на Kaggle](https://www.kaggle.com/code/naum0v7/used-car-prices-classical)

## Бустинги и новые признаки

Команда `python main.py --stage boosting` сравнивает CatBoost, LightGBM и XGBoost на тех же пяти фолдах. Для запуска одной библиотеки укажите `--estimator` с её именем в нижнем регистре. Путь к назначениям фолдов можно передать через `--folds-file`.

Для каждой библиотеки сначала проверяются исходные признаки и четыре варианта их расширения. Затем на лучшем наборе проверяются два дополнительных профиля гиперпараметров. Сводка и ошибки отдельных фолдов сохраняются в `results/boosting/`.

[Сравнение бустингов](results/boosting/README.md) · [CatBoost](https://www.kaggle.com/code/naum0v7/used-car-prices-catboost) · [LightGBM](https://www.kaggle.com/code/naum0v7/used-car-prices-lightgbm) · [XGBoost](https://www.kaggle.com/code/naum0v7/used-car-prices-xgboost)
