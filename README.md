# Прогнозирование цен подержанных автомобилей

Курсовая работа по дисциплине «Основы искусственных нейронных сетей». Цель — оценить цену автомобиля по его характеристикам на данных соревнования [Regression of Used Car Prices](https://www.kaggle.com/competitions/playground-series-s4e9/overview). Метрика соревнования — RMSE.

## Проверка входных данных

Проект использует Python 3.11 или новее. В окружении, где pandas ещё не установлен, установите зависимости:

```bash
python -m pip install -r requirements.txt
```

В ноутбуке Kaggle подключите соревнование как источник данных. Из каталога с файлами проекта запустите:

```bash
python main.py
```

Если CSV лежат в другом каталоге, укажите его явно:

```bash
python main.py --data-dir /путь/к/данным
```

Скрипт читает `train.csv`, `test.csv` и `sample_submission.csv`, сверяет признаки, цены и идентификаторы, затем выводит сводку в JSON. Идентификатор и имя целевого столбца заданы в `config.toml`.
