## Влияние предобработки

- **Заполнение пропусков.** Для Ridge с one-hot замена пропусков самым частым значением вместо отдельной категории снизила RMSE на 2,23. Разница мала.
- **Кодирование.** Для Ridge с отдельной категорией пропусков one-hot снизил RMSE на 1 218,65 относительно ordinal.
- **Масштабирование.** Стандартизация года и пробега увеличила RMSE KNN на 554,03. Вывод относится к этим двум признакам и 50 соседям.
- **Модель.** Random Forest дал наименьшую ошибку. Она на 2 456,02 ниже лучшего бейзлайна этапа 3. Ridge с one-hot и заполнением по моде уступил лесу на 517,41 и обучился за 8,6 с суммарно по пяти фолдам.

Все преобразования обучались на четырёх обучающих фолдах и применялись к пятому. Числовые пропуски заполнялись медианами обучающего фолда. Для неизвестных категорий one-hot выдавал нули в соответствующем блоке, а ordinal — значение −1. Предупреждений о сходимости не возникло.
